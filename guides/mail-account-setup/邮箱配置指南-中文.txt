邮件小秘书：邮箱配置手把手教程（中文）
适用：Windows、Apple 芯片 Mac、Intel Mac。资料核对日期：2026-10-17。
官方网站可能调整菜单名称；以登录后看到的页面和管理员要求为准。

一、先分清要填什么
1. 首次打开软件，在“连接邮箱”区域选“邮箱服务商”。以后在“设置 > 邮箱”（Mac）或“邮箱与检查”（Windows）修改。多邮箱用户先点“添加邮箱”。

语言与语言包

界面、安装程序和卸载程序支持**简体中文、英文、西班牙文**。首次使用：中文系统选择中文，西班牙语系统选择西班牙文，其他系统使用英文；之后可在通用设置切换。Windows 安装程序提供“下载简体中文”“下载英文”“下载西班牙文”。

切换到尚未安装的语言时，会提示“你没有下载这个语言，是否现在下载？”。确认后下载；取消或下载失败保留当前语言。新报告跟随所选语言，六项分析要求不变；已有报告不会自动翻译。英文名称为 **Email Assistant**，西班牙文名称为 **Asistente de correo electrónico**。


2. “邮箱地址”填完整地址；“IMAP 收件服务器”只填域名，不加 https://、端口或路径。下列常见预设均用端口 993、SSL/TLS；自定义邮箱按官方说明填写。
3. “登录用户名”通常留空，软件使用完整邮箱地址；服务商另有要求才填。文件夹通常为 INBOX。
4. “密码／客户端授权码”与“OAuth2 访问令牌”是两种登录方式。没有通用的“IMAP码”。授权码／应用专用密码由邮箱网站生成，不是短信验证码；OAuth2 要填 access_token，不是 refresh_token、id_token 或授权码。
5. 把凭据填进软件的密码／授权码／OAuth2 访问令牌框，点“保存邮箱设置”（首次使用可能显示“保存并开始使用”），再点“测试邮箱连接”。更换连接信息前先暂停监听。
6. 邮箱凭据与 AI API Key 是不同的东西。不要把密码、授权码、令牌贴到聊天或发给陌生人。收到新邮件需要另外配置 AI；没有新邮件不会调用 AI。

如果你已经有AI软件，就让它们帮你获得授权码。
让 AI 帮你辨认官方入口和操作步骤；凭据只填邮箱官网或邮件小秘书，身份验证由你本人完成。

代理连接（例如中国大陆访问 Gmail）
1. 先启动 v2rayN 等代理软件，并确认节点可以连接。网页能打开不代表 IMAP 已经过代理。
2. 在邮箱设置选择要配置的账号，Windows 展开“高级连接与代理选项”；Mac 找到“邮箱代理”。旧账号默认“直连”。
3. 可先选择“系统代理”。软件读取系统／环境中实际配置的代理；找不到可用代理会报错，不会自动改为直连。
4. 若系统代理不可用，选择“HTTP 代理”或“SOCKS5 代理”，协议须与代理软件一致。地址通常为 127.0.0.1；端口请查看代理软件当前的本地监听端口，不能照抄示例。10808 只是常见示例。
5. 保存邮箱设置，再点“测试邮箱连接”；成功后恢复监听。每个邮箱可使用不同代理。自定义代理不要求开启 TUN。
6. 本功能仅代理 IMAP 收信连接，不会更改 AI 接口的网络设置。暂不支持 PAC 自动配置脚本或需要用户名／密码的代理。代理失败会显示错误，不会偷偷改为直连。

二、网易 163 / 126 / Yeah
官网分别为 https://mail.163.com/ 、https://mail.126.com/ 、https://www.yeah.net/ 。官方帮助入口：https://help.mail.163.com/ 。
1. 用浏览器进入对应官网，登录自己的邮箱。
2. 在设置中找“POP3/SMTP/IMAP”或客户端相关设置，开通 IMAP 服务；不要只开 POP3。
3. 按页面提示做安全验证并生成客户端授权码。有的页面把“开通服务”和“新增授权码”放在一起；按当前页面完成手机等验证。若没有入口，先查看官方帮助或联系网易客服，不要从第三方买授权码。
4. 保存生成的授权码。它通常只在生成时完整显示；忘了可在官网撤销并重新生成。
5. 回软件，选对应预设，填完整地址与授权码，登录方式选“密码／客户端授权码”。163 用 imap.163.com；126 用 imap.126.com；Yeah 用 imap.yeah.net。端口 993，SSL/TLS。
6. 保存并测试连接。账号风控、安全验证或 IMAP 未开通时，需先在网页端解决；邮箱登录密码不能代替服务商要求的客户端授权码。

三、QQ 邮箱 / QQ 地址的 Foxmail
官网：https://mail.qq.com/ 。官方授权码说明：https://service.mail.qq.com/detail/0/75 。
1. 登录 QQ 邮箱网页版，打开“设置”，进入“账号”。
2. 找到“POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务”区域，开通 IMAP/SMTP 服务。
3. 按网页提示完成身份验证，获取授权码；生成或管理授权码的具体入口以当前页面为准。
4. 软件选“QQ / Foxmail”，填完整的 QQ 邮箱地址或该 QQ 邮箱已启用的 @foxmail.com 地址；服务器 imap.qq.com，993，SSL/TLS。授权码填进凭据框，登录方式为“密码／客户端授权码”。
5. 保存并测试。Foxmail 同时也是一个邮件客户端名称：只是“在 Foxmail 软件里收信”的其他公司邮箱，不能因此选 QQ 预设，应按真实服务商或“其他邮箱”配置。

四、腾讯企业邮箱
官网：https://exmail.qq.com/ 。官方客户端设置说明：https://hiflow.tencent.com/document/applications/tencent-exmail/ 。
1. 登录企业邮箱网页版。先检查企业是否允许 IMAP／第三方客户端；没有相关权限时联系公司管理员开通。
2. 在账户／安全或客户端设置中查看当前组织的客户端登录要求；若启用了安全登录，按页面验证并生成客户端专用密码。不同企业、管理版本和安全策略可能让入口不同，不要照搬个人 QQ 邮箱的入口。
3. 软件选“腾讯企业邮箱”，填完整企业邮箱地址，服务器 imap.exmail.qq.com，993，SSL/TLS，登录方式“密码／客户端授权码”。凭据按企业要求填专用密码；只有管理员明确允许普通密码时才使用它。
4. 保存并测试；企业禁用了 IMAP、第三方客户端或密码登录时，需管理员处理，反复更换密码不能绕过企业策略。

五、Gmail
官网：https://mail.google.com/ 。应用密码官方说明：https://support.google.com/accounts/answer/185833?hl=zh-Hans 。账户安全页：https://myaccount.google.com/security 。
1. 登录 Google 账号，进入“安全性”，启用“两步验证”。
2. 打开 https://myaccount.google.com/apppasswords ，按提示再次登录，为“邮件小秘书”创建应用密码。
3. 将生成的 16 位应用密码填到软件；不要填 Google 常用登录密码。选 Gmail，填完整地址，imap.gmail.com，993，SSL/TLS，“密码／客户端授权码”，保存并测试。
4. 只有安全密钥的两步验证、Google 高级保护计划、工作／学校账号的管理员限制等情况可能看不到应用密码。软件目前没有 Google 网页 OAuth 登录流程；没有应用密码时不要关闭账号安全保护硬凑连接，应咨询管理员或换可用账号。
5. 改 Google 账号密码会撤销应用密码，届时需重新生成并更新软件。

六、iCloud 邮箱
官网：https://www.icloud.com/mail/ 。官方应用专用密码说明：https://support.apple.com/102654 。服务器说明：https://support.apple.com/102525 。
1. 登录 https://account.apple.com/ ，先确保 Apple 账户已启用双重认证。
2. 进入“登录和安全 > App 专用密码”，选“生成 App 专用密码”或“+”，命名为“邮件小秘书”，按提示验证。
3. 软件选 iCloud，填实际 iCloud 邮箱地址和生成的专用密码。服务器 imap.mail.me.com，993，SSL/TLS，登录方式“密码／客户端授权码”。
4. Apple 官方说明登录用户名通常是地址 @ 前面的部分；完整地址连接失败时，在高级选项“登录用户名”中填地址 @ 前部分再测试。自定义域名或别名以 Apple 账号的有效邮箱和官方要求为准。
5. 保存并测试。重设 Apple 账户主密码会自动撤销所有 App 专用密码，需要重新生成。不能使用 Apple 账户主密码代替。

七、Yahoo Mail
官网：https://mail.yahoo.com/ 。官方应用密码说明：https://help.yahoo.com/kb/SLN15241.html 。IMAP 说明：https://help.yahoo.com/kb/SLN4075.html 。
1. 登录 Yahoo 账户，进入“Account Security / 账户安全”，找到“Generate and manage app passwords / 生成和管理应用密码”。
2. 按网页提示输入应用名“Email Assistant”，生成并复制应用密码。
3. 软件选 Yahoo，完整邮箱地址，imap.mail.yahoo.com，993，SSL/TLS，“密码／客户端授权码”。填生成的应用密码，保存并测试。
4. 若账户暂时不能生成应用密码，按 Yahoo 官网提示处理或联系其支持；不能保证所有账号都有该入口，也不要用短信验证码代替应用密码。

八、Outlook.com / Hotmail / Microsoft 365（OAuth2 完整步骤）
添加Outlook/Microsoft 365邮箱极其困难，强烈不推荐，如果你爱折腾，下面有完整步骤：

官网与入口：
个人邮箱：https://outlook.live.com/mail/
工作／学校邮箱：https://outlook.office.com/mail/
Microsoft Entra 管理中心：https://entra.microsoft.com/
Azure 账户注册：https://azure.microsoft.com/pricing/purchase-options/azure-account

先了解：邮件小秘书目前让你使用自己注册的应用和手动取得的 OAuth2 access_token，没有内置微软网页登录或自动续期。令牌会过期，之后还要重新登录取令牌。普通邮箱密码、应用密码、应用 ID、租户 ID 和访问令牌是不同的东西，不能互相代填；Microsoft Graph / Graph Explorer 的令牌也不能拿来登录 IMAP。
如果只想统一看邮件，支持微软登录的邮箱客户端通常更省事，但邮件小秘书不能直接读取其他客户端里的账号或邮件。若想让小秘书继续分析，可在 Outlook 网页设置自动转发到已经接入小秘书的邮箱，勾选保留副本，并发信测试是否送达。组织可能禁止转发；附件是否完整也要实测。接收方不要再自动转发回 Outlook，以免形成循环。

A. 检查邮箱是否允许 IMAP
1. 在浏览器登录要接入的邮箱。个人 Outlook 打开右上角齿轮“设置 > 邮件 > 转发和 IMAP”，启用允许设备和应用使用 IMAP 的选项，保存。若菜单不同，在设置里搜索“IMAP”。
2. Microsoft 365 工作／学校邮箱，请管理员确认这个邮箱已启用 IMAP，并允许后面的应用、用户授权及设备代码登录。没有该权限时不能靠反复取令牌解决。

B. 准备能注册应用的目录（你可能卡在这里）
3. 打开 Microsoft Entra 管理中心，登录准备用来管理应用的账号。已有组织目录时，从右上角账号菜单的“切换目录”选择你有权限的目录。管理应用的账号与实际收邮件的账号可以不同，但应用必须支持收邮件账号的类型。
4. 如果个人 Outlook 账号登录后报 AADSTS50020、“用户帐户在租户 Microsoft Services 中不存在”，说明当前账号不能进入该目录；截图中的 ADIbizaUX／74658136-14ec-4630-ad9b-26e160ff0fc6 是微软门户的应用 ID，不能填进邮件小秘书。重复登录和改 Cookie 都不能给你增加目录权限。请使用自己有权限的目录，或请组织管理员提供合适的应用注册权限。
5. 如果你没有可用目录，可以打开上面的 Azure 账户注册页面，查看自己是否符合“免费账户”的注册条件。仅仅拥有 Outlook 邮箱或登录 Entra，不等于已经完成 Azure 注册。
   注册顺序：选择“免费账户／免费开始” > 登录你的微软账号 > 按官网表单填写账户资料并验证手机 > 在微软官方页面完成银行卡验证 > 核对当前免费条款后提交。若出现购买、付费升级或与你预期不同的条件，先停止并确认，不要直接开通。
   普通 Azure 免费账户注册通常要求手机和符合要求的信用卡／借记卡进行身份验证，可能有临时预授权。不要把银行卡信息、验证码发给 AI 或写进本软件。免费账户与“按量付费”是不同选项，按官网当时展示的条款选择；不要为了本教程直接升级付费。
   完成首次 Azure 账户注册后，回到 Entra，重新登录并从右上角账号菜单“切换目录”，选择注册时生成的目录（常见名称为 Default Directory／默认目录）；使用这个目录注册应用，不需要另建租户。目录创建有资格限制，免费／试用账号不能在 Entra 管理中心新建额外的 Workforce 目录。若首次注册没有提供可用目录，或“新注册”被禁止，先停下来请管理员协助，或使用前面的转发方案。
6. 进入自己可用的目录后，打开“Entra ID（旧界面可能叫‘标识’）> 应用注册”。若无“新注册”按钮、按钮灰色或提示无权限，需要管理员授予注册权限。不要把门户首页的“租户 ID”当成“应用 ID”。

C. 一次性注册应用并配置 IMAP 权限
7. 点击“应用注册 > 新注册”。名称填“Email Assistant”；支持的账户类型按收邮件账号选择：
   - 个人 Outlook／Hotmail：选“仅个人 Microsoft 账户”，或同时包含组织目录与个人 Microsoft 账户的选项。
   - 仅本单位 Microsoft 365：可选“仅此组织目录中的账户（单租户）”。
   - 需要同时支持个人和不同组织：选包含任意组织目录及个人 Microsoft 账户的选项；组织仍可能要求管理员批准。
   本工具使用设备代码流程，“重定向 URI”留空即可，然后点击“注册”。
8. 注册完成后进入这个应用的“概述”。复制“应用程序（客户端）ID”（形如 xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx）。这是终端里要填的应用 ID。工作／学校邮箱还要记下对应的“目录（租户）ID”。不要复制“对象 ID”，也不要复制其他应用的 ID。
9. 在这个应用的“身份验证 > 高级设置”（界面也可能显示为“设置／高级设置”）中，将“允许公共客户端流”设为“是”，点击“保存”。本工具不需要创建客户端密码或证书，不要在终端填邮箱密码或客户端密码。
10. 打开“API 权限 > 添加权限 > 我的组织使用的 API”，搜索“Office 365 Exchange Online”，选择它，再选择“委托的权限”，展开 IMAP 并勾选“IMAP.AccessAsUser.All”，点击“添加权限”。不要选 Microsoft Graph 的 Mail.Read，也不要选应用程序权限或 IMAP.AccessAsApp。
    随软件附带的工具会自动请求 https://outlook.office.com/IMAP.AccessAsUser.All offline_access，不需要你修改脚本或复制 PowerShell 代码。
11. 若目录要求管理员同意，请管理员审查后批准。没有管理员按钮或不能点击时不要勉强；个人账号通常在后面的登录授权页同意。组织禁止该应用或设备代码流程时，需要管理员处理。

D. 用随软件附带的工具取得访问令牌
工具用途：向微软申请设备代码登录，显示官方网址和一次性代码；你在浏览器确认授权后，它把 access_token 复制到剪贴板。不显示令牌全文，不写入令牌文件，也不需要你在工具里输入邮箱密码。163、QQ 等不需要微软 OAuth2 的邮箱跳过本节。
12. 回邮件小秘书，选 Outlook／Microsoft 365 预设及“OAuth2 访问令牌”。点击“如何获取授权码？”旁的“获取 OAuth2 Token”按钮。
    Windows：按钮运行安装目录中的 Get-Outlook-Token.bat，它会调用旁边的 PowerShell 脚本；保持两个文件在一起，不用手动粘贴代码。
    Mac：按钮打开随软件附带的 Get-Outlook-Token.command 和内置取令牌工具，不需要另装 PowerShell。
13. 工具询问“应用程序（客户端）ID”时，粘贴第 8 步复制的 ID，按回车。不能填邮箱地址、租户 ID、普通密码或 AI API Key。
14. 工具询问“租户”时：
    - 个人 Outlook／Hotmail：直接回车，使用默认 consumers。
    - 工作／学校邮箱：输入收邮件账号所在组织的目录（租户）ID，并确保该应用支持该组织。
15. 浏览器打开工具显示的微软官方登录网址（通常是 https://microsoft.com/devicelogin ），输入本次工具显示的一次性代码；此代码不是邮箱密码，也不是访问令牌。登录要监听的邮箱，核对应用名称和权限，再同意。不要将别人发来的代码用于这一步。
16. 保持终端窗口开启，等它显示“访问令牌已复制”。如果代码或登录超时，重新运行工具，从头取得新代码。

E. 把令牌填回邮件小秘书并测试
17. 邮箱地址：填写刚才授权的完整邮箱地址。
    IMAP 服务器：outlook.office365.com
    端口：993
    加密：SSL/TLS
    登录方式：OAuth2 访问令牌
    凭据框：粘贴刚复制的 access_token。
    “高级连接选项 > 登录用户名”通常留空，默认跟随邮箱地址；管理员有明确要求时再填写。
18. 点击保存，再点击“测试邮箱连接”。成功后开始监听。首次检查只记录起点，之后的新邮件才生成报告；可以另发一封新邮件验证。
19. 保存后复制一段普通文字覆盖剪贴板；不要把完整令牌贴到聊天、截图或教程中。
20. 访问令牌会过期，常见默认有效期为 60～90 分钟，实际以微软返回值及组织策略为准。即使申请了 offline_access，当前工具也不会保存或使用刷新令牌；需要重新点击取令牌按钮、重新授权，并更新软件里的凭据。因此当前微软邮箱直连方式不适合希望长期无人值守的用户。

F. 常见卡点（按错误处理，不要只反复重试）
- AADSTS50020／Microsoft Services：回第 3～6 步检查目录及权限。你不能自行把账号加入微软拥有的 Microsoft Services 租户；换一个自己有权访问的目录。若错误发生在取令牌登录阶段，也检查第 7、14 步的账户类型和租户是否匹配。
- AADSTS50058／“需要交互”：先点“重新登录”，主动选择账号。仍重复时检查浏览器会话、Cookie 或拦截扩展；必要时换一个已正常登录的浏览器。Safari 若临时关闭“防止跨站跟踪”排查，完成后恢复。这个操作无法解决 AADSTS50020 的目录权限问题。
- 找不到应用 ID：打开你自己注册的那个应用的“概述”，找“应用程序（客户端）ID”；不是租户 ID、对象 ID，也不是网页错误里的门户应用 ID。
- invalid_client／unauthorized_client：核对应用 ID、账户类型和“允许公共客户端流”，确认已保存。
- consent_required／需要管理员批准／access_denied：检查委托权限及组织策略；请管理员审查，不要改用普通密码。
- 取令牌成功但 IMAP 认证失败：核对邮箱是否已开 IMAP、令牌是否对应同一邮箱且尚未过期，以及申请的是 Exchange Online 的 IMAP scope，而不是 Microsoft Graph 的令牌。组织策略仍可能阻止登录。

九、其他邮箱（最简单的顺序）
1. 进这个邮箱服务商自己的官方网页版邮箱，登录。
2. 在官网设置或官方帮助中找 IMAP／第三方客户端，开通 IMAP；没有入口就联系该邮箱客服或单位管理员。不同服务商菜单不同，没有统一的开通按钮。
3. 按官网要求取得客户端授权码／应用专用密码；如果必须 OAuth2，请向管理员取得适用于该 IMAP 服务的 access_token。本软件没有通用 OAuth 登录或自动续期功能。
4. 回软件选“其他邮箱／自定义 IMAP”，填完整邮箱地址、官方提供的 IMAP 域名、端口、加密方式与登录凭据；“高级连接选项”按需填登录用户名和邮件文件夹。不要猜服务器名，也不要把 SMTP 发件服务器填到 IMAP 中。
5. 保存好，点“测试邮箱连接”；成功后开始监听。官网要求 STARTTLS 就选 STARTTLS 并用官方端口，不要套用别家的 993。服务商只提供 POP3、要求本软件尚不支持的登录方式或禁止第三方客户端时，当前不能连接。

十、连接不通先看这里
域名／端口错误：回官网核对 IMAP，不要填网页 URL。
认证失败：检查登录方式、完整账号、授权码是否撤销、OAuth 令牌是否过期。
组织策略拒绝：联系管理员；软件不能解除限制。
测试成功但没有旧邮件报告：首次检查只记录已有邮件，之后的新邮件才生成报告。
