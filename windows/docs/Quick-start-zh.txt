邮件小秘书 Windows 使用指南

一、安装与第一次打开
1. 需要 Windows 10 / 11，x64。运行安装程序，选择安装目录、桌面／开始菜单快捷方式和需要下载的语言包。
2. 安装器会检查 .NET 8 与 Windows App Runtime 1.8（WinUI 3），缺少时先请你确认，再下载安装；已有兼容组件会复用。无需安装 Python 或打开命令行。
3. 首次配置选择邮箱预设；不在列表中选“其他邮箱（自定义 IMAP）”。在邮箱服务商网页开启 IMAP，填写完整邮箱地址、IMAP 服务器、端口、加密和服务商要求的授权码、应用专用密码或 OAuth2 访问令牌。高级选项的登录用户名通常留空。
4. “如何获取授权码？”会打开完整教程。不要把授权码或令牌发给别人。保存后测试邮箱连接。

二、AI 和报告
1. 在“AI 服务”选择 API，或本机已安装配置好的 Codex／DeepSeek Harness。API 需要基础地址、API Key 和模型名。软件不会捆绑或下载 Harness。
2. 保存并测试 AI；手动测试可能消耗少量 Token。在“通用设置”的报告保存位置点击“浏览……”选择文件夹，必要的目录会自动创建。
3. 新邮件报告包括：新邮件提醒、谁发的、说了啥、我要干什么、附件内容、建议回复。不会自动发送回复。没有新邮件或待重试任务时，不调用 AI。

三、多邮箱与监听
1. 在“邮箱与检查”添加账号。各账号分别保存连接、凭据、代理和进度；AI、报告目录、检查间隔共用。
2. 主窗口点击“开始监听”或“暂停监听”；“立即检查”会请求立即检查。
3. 检查间隔可填 10–86400 秒；默认 60 秒。新账号第一次检查只记录收信起点，不分析所有旧邮件。恢复监听会补查暂停、关机期间收到且仍在所选文件夹的新邮件。

四、阅读、筛选、搜索
1. 左侧选报告，右侧阅读全文；时间单独显示。新文件为 Markdown（.md），支持格式化预览；旧 TXT 继续可读。文件名仍包含收到时间。
2. 搜索本机已保存的正文、发件人、附件名；不是搜索整个远端收件箱。可以组合日期、发件人、有无附件筛选，重置可清除筛选。

五、代理
启动 v2rayN 等代理软件。在邮箱高级连接与代理选项选系统代理、HTTP CONNECT 或 SOCKS5，填写实际监听地址、端口和协议。选择系统代理需先在客户端启用系统代理。保存后测试。代理失败不会悄悄直连；显式代理不需要 TUN。只影响 IMAP，不改变 AI API 网络；不支持 PAC 或需要用户名密码的代理。

六、语言
首次使用：中文系统选中文，西班牙语系统选西班牙文，其他系统选英文。在通用设置切换。未下载时询问“你没有下载这个语言，是否现在下载？”，确认后下载，取消或失败保留当前语言。
新报告使用所选语言，六项分析要求不变；旧报告不会自动翻译。英文名称为 Email Assistant，西班牙文名称为 Asistente de correo electrónico。

七、更新、退出、卸载
在“通用设置”检查更新；每小时也会自动检查。下载在软件内完成，可查看进度并取消。校验通过后点击安装，保留配置、报告与快捷方式选项；安装失败会尝试恢复旧版。
关闭窗口后仍在系统托盘监听，点击信封恢复窗口；从托盘菜单退出会停止本次监听。可选开机登录 Windows 后启动。
从卸载快捷方式或 Windows“已安装的应用”卸载。软件仍在运行时会询问是否退出；有邮件任务时先等待完成。配置和报告可分别选择保留，删除报告会二次确认。
安装包没有发布者签名；Windows 若提示风险，请先核对 GitHub 下载来源与 SHA256。
