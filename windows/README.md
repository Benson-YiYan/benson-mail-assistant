# 邮件小秘书 · Windows

[English](README.en.md) · [Español](README.es.md)

把每封新邮件整理成六项报告：**新邮件提醒、发件人、摘要、待办、附件内容、建议回复**。
支持多个邮箱、自选 AI、Markdown 预览、搜索和筛选。没有新邮件或待重试任务时，不调用 AI；不会自动发送回复。

## 下载与安装

适用于 **Windows 10 / 11，x64**。

1. 从 [GitHub Releases](https://github.com/Benson-YiYan/benson-mail-assistant/releases/latest) 下载 `BensonMail-Windows-x64-Setup-<版本号>.exe`，然后双击运行。
2. 按向导选择安装位置，并选择需要的桌面、开始菜单快捷方式。
3. 安装后打开“邮件小秘书”。完成页可选择删除本次下载的安装程序。

安装包可直接从公开 Release 下载。已安装用户也可在软件内点击“检查更新”。版本号按打包时的北京时间生成，格式为“年月日时分”。Release 附带 `SHA256SUMS.txt`，可用于核对安装包完整性。

**无需安装 Python 或打开命令行。API 模式无需安装 Codex。** 安装器会检测 **.NET 8（x64）** 和 **Windows App Runtime 1.8（x64，提供 WinUI 3）**。缺少时列出组件并再次征求确认，确认后才下载和安装；已有兼容组件直接复用。安装共享组件时可能需要管理员批准。拒绝或组件安装失败时，不开始覆盖旧版。升级成功后，仅按文件清单及 SHA256 删除旧版程序目录里已停用的运行库副本；卸载软件不会删除系统共享运行库。 当前安装包未做发布者代码签名；遇到 Windows 提示时，请先核对文件来源。

## 第一次使用

### 1. 邮箱

在首次向导或左侧“邮箱与检查”中：

1. 选择服务商；没有对应预设就选“其他邮箱（自定义 IMAP）”。
2. 填完整邮箱地址，以及服务商要求的客户端授权码、应用专用密码或 OAuth2 访问令牌。不要把所有邮箱都当作使用网页登录密码。
3. 自定义邮箱需填写 IMAP 服务器、端口及加密方式。预设也需要在服务商处启用 IMAP。
4. 点击“如何获取授权码？”查看逐步教程，再保存并点击“测试邮箱连接”。

预设包括 163、126、Yeah、QQ/Foxmail、腾讯企业邮箱、Gmail、Outlook/Microsoft 365、iCloud 和 Yahoo。
OAuth2 目前需手动填写、更新有效访问令牌。微软辅助工具还需要可用的客户端 ID 和网页授权；企业账号可能需要管理员批准，工具不会自动刷新令牌。

### 2. AI

在“AI 服务”中选一种方式，保存后测试连接：

| 方式 | 需要准备 |
| --- | --- |
| API | 兼容 Chat Completions 的基础地址、API Key 和模型名 |
| Codex | 已安装、登录且有可用命令行组件的 Codex |
| DeepSeek Harness | 已安装并配置好模型、支持 `headless --json` 的 Harness |

API 地址可以是服务商提供的基础地址（例如以 `/v1` 结尾）或完整 `/chat/completions` 地址。Harness 使用用户已有的安装，不随软件捆绑或自动下载。测试 AI 连接会发送少量文字，可能产生服务商费用。

### 3. 保存位置与监听

在“邮箱与检查”点击“浏览……”选择报告文件夹，然后“开始监听”。

- 默认每 **60 秒**检查一次，可自定义为 **10–86400 秒**。
- **新添加邮箱第一次检查只记录当前位置，不会分析收件箱里的全部旧邮件。**
- 已有收信进度时，恢复后会补查暂停、关机期间的新邮件，前提是邮件仍在所选文件夹中。
- 修改邮箱或 AI 设置前，先暂停监听并等待当前任务结束。

## 报告、搜索和筛选

“邮件报告”左侧选邮件，右侧阅读。新文件保存为 `所选文件夹/日期/邮件标题-收到时间.md`，使用北京时间，重名会避让。
Markdown 预览支持标题、加粗、列表、链接、表格和代码块；旧 `.txt` 仍可查看、搜索和筛选。
搜索使用本机保存的正文、发件人、附件名和报告文字；可组合日期、发件人、有无附件筛选。它不会搜索整个远端邮箱。
“打开报告”打开原文件，“打开报告文件夹”打开保存位置。

## 更新、退出与卸载

- **更新：**每 5 小时自动检查，也可手动检查。在软件内下载、校验后，由用户点击安装；保留配置、报告及原快捷方式选择。
- **关闭窗口：**继续在系统托盘监听；点击信封恢复窗口。“退出”会停止本次监听。可选择登录 Windows 后自动启动。
- **卸载：**使用卸载快捷方式或 Windows“已安装的应用”。软件运行时先询问是否退出；有邮件正在处理时，等待完成再重试。
- “保留邮箱及 AI 配置”和“保留邮件报告”分别控制保留内容；删除报告会再次确认。保留的加密凭据只适用于本机同一 Windows 用户。

## 连接失败怎么办

先“测试邮箱连接”，复制显示的**阶段、异常类型和服务器响应**用于排查。

| 报错 | 先检查 |
| --- | --- |
| 认证失败 / `AUTHENTICATIONFAILED` | 完整账号、授权码或有效令牌，以及服务商认证要求 |
| IMAP 未开启 | 网页邮箱设置或企业管理员策略 |
| `Unsafe Login` | 网页邮箱安全提醒、第三方客户端限制 |
| DNS / 超时 / TLS | IMAP 地址、端口、网络、系统时间和代理 |

旧版若只显示“操作失败，请检查设置与文件权限”，请先更新。这个通用提示无法证明是权限问题。

## 数据与语言

邮箱凭据和 API Key 使用 Windows 当前用户的加密机制保存。来信和可提取的附件内容会发送给您选择的 AI。邮箱访问只读，不自动回复；图片、扫描件、加密及不支持的附件会说明读取限制。使用建议回复前，请核对原邮件。
首次启动按系统语言选择简体中文、西班牙文或英文，可手动切换。新报告跟随界面语言，回复草稿使用来信语言；已有报告保持原文。

## 语言与语言包

界面、安装程序和卸载程序支持**简体中文、英文、西班牙文**。首次使用：中文系统选择中文，西班牙语系统选择西班牙文，其他系统使用英文；之后可在通用设置切换。Windows 安装程序提供“下载简体中文”“下载英文”“下载西班牙文”。

切换到尚未安装的语言时，会提示“你没有下载这个语言，是否现在下载？”。确认后下载；取消或下载失败保留当前语言。新报告跟随所选语言，六项分析要求不变；已有报告不会自动翻译。英文名称为 **Email Assistant**，西班牙文名称为 **Asistente de correo electrónico**。

## 邮箱代理

每个邮箱可分别选择直连、系统代理、HTTP CONNECT 或 SOCKS5。在邮箱设置中打开高级连接与代理选项；启动 v2rayN 等代理软件，填写其实际监听地址、端口和协议，保存后测试连接。代理失败不会悄悄改成直连。这只影响 IMAP 测试与收信，不改变 AI API 网络；不支持 PAC 脚本或需要用户名密码的代理。
