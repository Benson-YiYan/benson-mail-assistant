Mail Assistant
邮件小秘书

A desktop email assistant for macOS and Windows.
面向 macOS 和 Windows 的桌面邮件助手。

What it does / 功能简介

Mail Assistant reads mail from folders selected by the user, prepares summaries and lets the user ask questions about a message. It can also prepare an editable reply draft. The user reviews and confirms any outgoing email.

邮件小秘书读取用户选择的邮箱文件夹，生成邮件摘要，并支持围绕邮件提问。它也可以准备可编辑的回复草稿；任何外发邮件都需要用户查看并确认。

Data use / 数据使用

Mail content and readable attachment text stay on the user's computer unless the user runs an AI feature. When an AI feature is used, relevant content is sent to the AI provider configured by the user. See the privacy policy for details.

邮件内容和可读取的附件文字默认保存在用户电脑上。用户执行 AI 功能时，相关内容会发送给用户配置的 AI 服务。详情请阅读隐私政策。
