# Benson 邮件小秘书 · Windows 10/11 x64

## 妈妈的使用说明

1. 把 ZIP 完整解压到您方便的位置。不要只拖出 EXE；旁边的 `_internal` 文件夹也需要保留。
2. 双击 `BensonMail.exe`。无需安装 Python，也不用打开终端。程序尚未签名，Windows 可能显示发布者未知；请先确认安装包由 Benson 提供。
3. 在 163 网页邮箱的设置中开启 IMAP，获取**客户端授权码**。填写邮箱与授权码，不要填写网页登录密码。
4. 选择报告保存文件夹。默认是 Windows 实际“文档”文件夹下的“邮件”，支持 OneDrive 重定向。
5. 左侧“AI 服务”选择 API，填写基础地址（服务商提供的 `/v1` 地址）、API Key、模型名，点击“保存 AI 设置”。支持 OpenAI 兼容的 Chat Completions 接口，自动补全 `/chat/completions`；此模式无需安装 Codex。可手动“测试 AI 连接”，测试会发送简短消息，可能消耗少量 Token。修改 AI 配置前先暂停监听，等当前工作结束。
6. 点击“开始监听”。首次运行只记录现有邮件，不分析旧邮件。默认每分钟检查一次，可在左侧“自定义检查间隔”修改为10–86400秒；暂停／关机期间的新来信会在恢复后补查。

窗口采用左右布局，右侧邮件报告占满窗口高度，分栏宽度可拖动。邮件主题与收到时间分别显示，文件名保持原有命名。支持本地正文、发件人和附件名搜索，以及日期、发件人、有无附件组合筛选。旧报告没有原邮件缓存时，只能搜索报告文字，附件状态未知。

旧用户的 Codex 模式保留。在“AI 服务”选择 Codex 并完成登录，可继续使用原流程；程序自动寻找命令行组件，也可选择安装目录 `resources` 内的 `codex.exe`。桌面主程序不等于命令行程序。

报告位于“邮件／日期／标题-收到时间.txt”，按北京时间命名。重名会加 UID 编号，不覆盖原文件。报告包含提醒、发件人、中文摘要、待办和截止时间、附件内容、建议回复；双击最近报告即可查看。AI 分析结果可能有误，请核对原邮件后再回复。

收到新邮件和报告整理完成时会发送系统通知；Windows 的专注助手或通知设置可能隐藏提示。重试不会重复发送同一封邮件的提醒。新来信和报告完成时会发出系统通知；Windows 通知设置或勿扰模式可能影响弹出显示。关闭窗口后在右下角蓝色信封托盘继续运行；点击信封恢复窗口。暂停仍会保留待处理邮件；“退出程序”会停止监听。勾选“登录 Windows 后自动启动”才会设置自动启动。请将解压后的程序保存在固定位置，自启动后移动文件会导致启动失败。退出前的监听状态会在下次启动时恢复。

## 资料与连接

- 授权码仅通过当前 Windows 用户的 DPAPI 加密，和对应邮箱绑定。配置和处理进度保存在 `%LOCALAPPDATA%\BensonMail`；不上传 GitHub。换 Windows 用户或换电脑后需重新填写授权码。
- 来信与可读取的附件文本会交给您选择的 AI 服务分析。API Key 使用当前 Windows 用户的 DPAPI 加密，并绑定基础地址，不写入普通配置。填写新地址时需提供对应 Key；模型名可直接修改。原提示词及六项要求保持不变，不发送邮箱授权码给 AI。
- 邮箱只读，不改变已读状态，不自动回复。不执行附件、宏、来信指令或链接。
- 可提取 TXT/CSV、DOCX、XLSX、PPTX 文字和 PDF 文字层。图片、扫描 PDF、旧 Office 文件、加密或损坏附件会明确标注限制；Office 图片、图表及原始排版不识别。Excel 按工作表、行、单元格解析共享文字与数值；公式仅使用文件内保存的缓存值，不重新计算，日期及金额格式不还原。大附件与长内容有读取上限。
- 网络失败或 AI 失败会保留任务并自动重试；保存失败会重试已缓存的报告，不重复请求 AI。邮箱 UIDVALIDITY 改变后重新记录基线，避免把旧邮箱数据误当新来信。
- “测试连接”检查真实邮箱只读连接及所选 AI。API 模式会发送简短测试请求。自动化测试仅使用虚构来信和本机模拟 API，不代表您电脑的服务商 Key 和网络已通过。

## 开发与验证

Python 3.12：`python -m pip install -r requirements.txt`；`python -m unittest discover -s tests -v`。
Windows 构建运行 `./build.ps1`。GitHub Actions 在 Windows 2022 上执行单元测试、真实 Tk 窗口截图、Windows DPAPI/文档目录/注册表检查、完整模拟来信流程，然后打包并运行 EXE 自检。安装包与测试记录分别作为 artifacts 下载。

`python main.py --self-test RESULT.json --screenshot SCREEN.png` 使用临时目录、模拟邮箱和本机 HTTP 测试服务，不访问真实邮箱或 AI 服务；在 Windows 上临时启动实际测试托盘、调用通知与关闭接口后清理。系统是否显示通知受 Windows 设置控制。自检仅临时创建测试专用自启动注册表值并清理，不改变正式应用自启动项。
