# Benson 邮件小秘书 · Windows 10/11 x64

## 妈妈的使用说明

1. 双击 `BensonMail-Windows-x64-Setup-年月日时分.exe`，按安装向导选择位置。版本号为打包时的北京时间。程序包含 WinUI 3、.NET 与 Python 运行文件，无需另装这些运行环境，也不用打开终端。
2. 安装向导提供四项独立选择：创建程序的桌面快捷方式、创建卸载程序的桌面快捷方式、创建程序的开始菜单项目、创建卸载程序的开始菜单项目。安装后按所选入口打开“邮件小秘书”。程序尚未签名，Windows 可能显示发布者未知；请确认安装包由 Benson 提供。 安装完成页另有“删除此安装程序”（默认不勾选）：勾选并点击“完成”后，等安装器退出再删除本次下载的安装 EXE，已安装的软件保持可用；不勾选则保留安装包。

卸载：打开“卸载邮件小秘书”快捷方式，或系统“已安装的应用”中的卸载入口，也可双击程序目录中的 `Uninstall-BensonMail-年月日时分.exe`。它会清理本次程序目录（包括卸载程序自身）、缓存、自启动注册表项和指向本次程序目录的快捷方式。可选“保留邮箱及 AI 配置，下次重装不用再配置”：保留邮箱列表、AI 设置和 DPAPI 加密密钥，仅可由本机同一 Windows 用户在重装后继续读取；缓存和收信进度清除，重装首次检查重新记录当前位置。不勾选会清理全部配置和密钥。需要删除邮件报告时另行勾选对应选项；自选报告目录中的其他文件会保留。下载的安装程序、另行复制的旧版本及 Windows 自身的运行历史不属于本次卸载范围。

卸载界面同样使用原生 WinUI 3、Fluent 卡片和 Mica 背景。它先准备位于临时目录的独立进程，再显示清理进度；结束后显示成功或具体失败原因。此过程不依赖 PowerShell，点击完成或关闭后临时进程清理自身文件。API 的 HTTPS 连接使用 Windows 原生证书验证并附带 CA 证书包，始终检查证书和域名。
3. 首次打开的向导和“邮箱与检查”均支持163、126、Yeah、QQ/Foxmail、腾讯企业邮箱、Gmail、Outlook/Microsoft 365、iCloud、Yahoo 预设及“其他邮箱（自定义 IMAP）”。先在服务商处启用 IMAP，按要求使用客户端授权码或应用专用密码。服务器、端口、SSL/TLS 或 STARTTLS、登录用户名及邮件文件夹均可修改；所有连接强制加密。需要 OAuth2 的邮箱可手动填写已取得的访问令牌，过期需手动更新；本版尚无浏览器 OAuth 登录及自动刷新。企业策略可能限制 IMAP。首次向导和邮箱设置均有“如何获取授权码？”按钮，打开程序目录内随界面语言选择的 TXT 教程，包含各预设邮箱官网和逐步操作，也有其他邮箱的通用说明。
4. 在左侧“邮箱与检查”中点击“浏览……”选择报告保存文件夹。默认是 Windows 实际“文档”文件夹下的“邮件”，支持 OneDrive 重定向。
5. 左侧“AI 服务”选择 API，填写基础地址（服务商提供的 `/v1` 地址）、API Key、模型名，点击“保存 AI 设置”。支持 OpenAI 兼容的 Chat Completions 接口，自动补全 `/chat/completions`；此模式无需安装 Codex。可手动“测试 AI 连接”，测试会发送简短消息，可能消耗少量 Token。修改 AI 配置前先暂停监听，等当前工作结束。
6. 点击顶部“开始监听”。首次运行只记录现有邮件，不分析旧邮件。默认每分钟检查一次，可在“邮箱与检查”的“自定义间隔”修改为10–86400秒；暂停／关机期间的新来信会在恢复后补查。

多个邮箱：在“邮箱与检查”点击“添加邮箱”，填写并保存；已有账号不会被覆盖。“已添加的邮箱”可切换编辑对象，支持分别启用、暂停和移除。顶部开始／暂停控制全部监听，立即检查会检查所有正在监听的账号。编辑连接前先暂停全部监听。每个连接独立记录收信进度，AI、报告目录与检查间隔共用；历史报告保留。

窗口采用原生 WinUI 3 侧栏导航和卡片布局。进入“邮件报告”，左栏选邮件，右栏通高阅读报告；邮箱和 AI 设置各有独立页面，保存按钮固定在页面底部。邮件主题与收到时间分别显示，文件名保持原有命名。顶部搜索框支持本地正文、发件人和附件名搜索，点击“筛选”可按日期、发件人、有无附件组合筛选。日期点击后才弹出日历。旧报告没有原邮件缓存时，只能搜索报告文字，附件状态未知。后台进程隐藏控制台窗口，日常使用无需打开 CMD。

旧用户的 Codex 模式保留。在“AI 服务”选择 Codex 并完成登录，可继续使用原流程；程序自动寻找命令行组件，也可选择安装目录 `resources` 内的 `codex.exe`。桌面主程序不等于命令行程序。

新报告位于“邮件／日期／标题-收到时间.md”，按北京时间命名。重名会加 UID 编号，不覆盖原文件及旧 TXT 报告。报告包含提醒、发件人、摘要、待办和截止时间、附件内容、建议回复；选中报告即可查看 Markdown 排版，也可点击“打开报告”查看原文件。标题、加粗、列表、链接、代码块和表格会在报告区显示；旧 TXT 报告仍支持查看、搜索和筛选。AI 分析结果可能有误，请核对原邮件后再回复。

收到新邮件和报告整理完成时会发送系统通知；Windows 的专注助手或通知设置可能隐藏提示。重试不会重复发送同一封邮件的提醒。新来信和报告完成时会发出系统通知；Windows 通知设置或勿扰模式可能影响弹出显示。关闭窗口后在右下角蓝色信封托盘继续运行；点击信封恢复窗口。暂停仍会保留待处理邮件；“退出程序”会停止监听。勾选“登录 Windows 后自动启动”才会设置自动启动。安装后请保留程序原位置，自启动后移动文件会导致启动失败。退出前的监听状态会在下次启动时恢复。

## 资料与连接

- 授权码仅通过当前 Windows 用户的 DPAPI 加密，和对应邮箱绑定。配置和处理进度保存在 `%LOCALAPPDATA%\BensonMail`；不上传 GitHub。换 Windows 用户或换电脑后需重新填写授权码。
- 来信与可读取的附件文本会交给您选择的 AI 服务分析。API Key 使用当前 Windows 用户的 DPAPI 加密，并绑定基础地址，不写入普通配置。填写新地址时需提供对应 Key；模型名可直接修改。中文提示词保持不变；英文界面使用对应的英文六项提示词，新报告使用英文，建议回复草稿按来信语言写并用英文解释。切换语言不改写已有报告，也不调用 AI。不发送邮箱授权码给 AI。
- 邮箱只读，不改变已读状态，不自动回复。不执行附件、宏、来信指令或链接。
- 可提取 TXT/CSV、DOCX、XLSX、PPTX 文字和 PDF 文字层。图片、扫描 PDF、旧 Office 文件、加密或损坏附件会明确标注限制；Office 图片、图表及原始排版不识别。Excel 按工作表、行、单元格解析共享文字与数值；公式仅使用文件内保存的缓存值，不重新计算，日期及金额格式不还原。大附件与长内容有读取上限。
- 网络失败或 AI 失败会保留任务并自动重试；保存失败会重试已缓存的报告，不重复请求 AI。邮箱 UIDVALIDITY 改变后重新记录基线，避免把旧邮箱数据误当新来信。
- “测试连接”检查真实邮箱只读连接及所选 AI。API 模式会发送简短测试请求。自动化测试仅使用虚构来信和本机模拟 API，不代表您电脑的服务商 Key 和网络已通过。

## 开发与验证

Python 3.12：`python -m pip install -r requirements.txt`；`python -m unittest discover -s tests -v`。
Windows 构建需要 .NET 8 SDK，运行 `./build.ps1`。GitHub Actions 在 Windows 2022 上执行后台单元测试、旧界面回归、Windows DPAPI/文档目录/注册表检查、完整模拟来信流程，然后编译原生 WinUI 3 窗口并运行实际 EXE 自检及卸载测试。安装包与测试记录分别作为 artifacts 下载。界面与后台通过本机重定向管道交换 JSON，不开放网络端口；密钥不会返回界面或写入普通配置。

`python main.py --self-test RESULT.json --screenshot SCREEN.png` 使用临时目录、模拟邮箱和本机 HTTP 测试服务，不访问真实邮箱或 AI 服务；在 Windows 上临时启动实际测试托盘、调用通知与关闭接口后清理。系统是否显示通知受 Windows 设置控制。自检仅临时创建测试专用自启动注册表值并清理，不改变正式应用自启动项。

## DeepSeek Harness

选择“DeepSeek Harness（使用已安装的应用）”，先在 Harness 中配置模型和登录。邮件小秘书自动查找 dsh，也可通过“浏览……”选择 dsh / dsh.cmd / dsh.exe（Mac 可选择 DeepSeek Harness.app）。不会捆绑、下载或安装 Harness，无需在邮件小秘书重复填写其 API Key。

使用已安装版本的 headless --json 接口与保存的凭据，每封邮件使用新会话，临时工作目录和覆盖配置不改变用户的配置。禁用命令执行与文件工具，原有六项提示词保持不变。会话记录按 Harness 自身规则保存在 Harness 中。无新邮件时不启动 Harness、不调用 AI。测试连接会发送少量测试文字。

需安装支持 headless --json 的 Harness 版本；未检测到或版本不兼容时显示提示。Harness 自身的登录及配置由其管理，邮件小秘书卸载不会移除 Harness。

## 中文 / English

首次启动按系统语言选择中文或英文（非中文系统用英文），可在设置切换，立即生效并记住。新报告的六项分析与解释使用所选语言；建议回复按来信语言写，历史报告不变。切换语言不调用 AI。

On first launch, Chinese system languages select Chinese; all others select English. Change the language in Settings. The choice is applied immediately and remembered. New six-section reports and explanations use that language; reply drafts follow the incoming message language. Existing reports are unchanged. Changing language does not call AI.
