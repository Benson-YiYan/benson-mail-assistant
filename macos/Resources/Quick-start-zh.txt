邮件小秘书 Mac 使用指南

一、第一次打开
1. 将邮件小秘书拖入“应用程序”，从“应用程序”打开。
2. 首次配置窗口中选择邮箱预设；不在列表中选“其他邮箱（自定义 IMAP）”。
3. 填完整邮箱地址、IMAP 服务器、端口和加密方式，按邮箱服务商要求填客户端授权码或 OAuth2 访问令牌。
4. 点击“如何获取授权码？”打开随软件附带的逐步教程。不要把密钥或令牌发送给别人。
5. 保存设置并测试邮箱连接。

二、AI 和报告
1. 在主窗口侧栏“AI 服务”中选择 API 或电脑已安装的受支持 AI 工具。使用 API 时填基础地址、API Key 和模型名，测试连接。
2. 在侧栏“通用设置”的“报告保存位置”点击“浏览……”选择报告保存目录；没有目录会自动创建。
3. 新邮件分析包括：新邮件提醒、谁发的、说了啥、我要干什么、附件内容、建议回复。不会自动发送回复。
4. 没有新邮件时不调用 AI。中文界面生成中文报告，英文界面生成英文报告；已有报告保持原样。

三、多邮箱与监听
1. 在侧栏“邮箱与检查”中添加邮箱，每个邮箱分别保存地址、连接信息和凭据。
2. 主窗口点击“开始监听”或“暂停监听”；“立即检查”可立即请求检查。
3. 在“邮箱与检查”中，“自定义检查间隔”可填 10 至 86400 秒，点击应用保存。60 秒为一分钟。

四、查看、筛选和搜索
1. 在侧栏“邮件报告”页左侧选择报告，右侧阅读完整内容；时间单独显示，新报告保存为 Markdown（.md），预览会渲染标题和排版；旧 TXT 仍可查看。文件名仍含收到时间。
2. 搜索可查邮件正文、发件人及附件名。
3. 点击“筛选”展开后，可按日期范围、发件人、有无附件组合筛选；重置可清除筛选条件。

五、更新与退出
1. 顶部“帮助 > 检查更新”或侧栏“通用设置”的更新区域可检查新版本。
2. 下载在应用内完成，可查看进度并取消；校验通过后点击“安装并重新打开”。
3. 软件检查安装包及应用并保留配置；安装失败会尝试恢复旧版本。
4. 关闭窗口后仍在菜单栏监听。通过 Dock、菜单或 ⌘Q 退出会停止监听，重新打开后点击“开始监听”恢复。
5. 界面语言可在侧栏“通用设置”中切换。首次启动按系统语言选择中文或英文。
