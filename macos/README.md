# 邮件小秘书 · Mac

[English](README.en.md) · [Español](README.es.md) · [项目总指南](../README.md)

把每封新邮件整理成六项报告：**新邮件提醒、发件人、摘要、待办、附件内容、建议回复**。
支持多个邮箱、自选 AI、Markdown 预览、搜索和筛选。没有新邮件或待重试任务时，不调用 AI；不会自动发送回复。

## 选择安装包

需要 **macOS 14 或以上**。点击苹果菜单 →“关于本机”，查看芯片类型：

| 电脑 | 安装包文件名包含 |
| --- | --- |
| Apple 芯片，如 M1、M2、M3、M4 | `Mac-AppleSilicon` |
| Intel 处理器 | `Mac-Intel` |

从公开的 [GitHub Releases](https://github.com/Benson-YiYan/benson-mail-assistant/releases/latest) 下载对应芯片的 DMG。Release 附带 `SHA256SUMS.txt` 供核对安装包完整性。

打开 DMG，把“邮件小秘书.app”拖入“应用程序”，再从那里打开。软件自带运行环境，无需安装 Python 或 Homebrew。API 模式无需 Codex。
安装包目前没有 Developer ID 签名及 Apple 公证；系统提示无法验证开发者时，请先核对来源。版本号按实际打包的北京时间生成。

## 第一次使用

1. **邮箱：**在首次向导选择服务商，或“其他邮箱（自定义 IMAP）”。填完整邮箱地址和服务商要求的授权码、应用专用密码或 OAuth2 访问令牌；自定义邮箱还需服务器、端口和加密方式。在网页邮箱启用 IMAP，点击“如何获取授权码？”查看逐步教程，保存后测试连接。
2. **AI：**在“AI 服务”选择下表中的一种方式，保存并测试。
3. **保存位置：**在“通用设置”点击“浏览……”选择报告文件夹，然后开始监听。

| AI 方式 | 需要准备 |
| --- | --- |
| API | 兼容 Chat Completions 的基础地址、API Key 和模型名 |
| Codex | 本机已安装、登录并有可用命令行组件的 Codex |
| DeepSeek Harness | 本机已安装并配置好模型、支持 `headless --json` 的 Harness |

API 地址可用服务商的基础地址（例如以 `/v1` 结尾）或完整 `/chat/completions` 地址。Harness 使用已有安装，不会随软件捆绑或自动下载。测试 AI 连接会发送少量文字，可能产生服务商费用。
邮箱预设包括 163、126、Yeah、QQ/Foxmail、腾讯企业邮箱、Gmail、Outlook/Microsoft 365、iCloud 和 Yahoo。预设仍需服务商授权；OAuth2 令牌过期需手动更新，企业账号可能受管理员策略限制。

## 四个页面怎么用

- **邮件报告：**左侧选邮件，右侧通高阅读。支持复制原文、打开报告、搜索及组合筛选。
- **邮箱与检查：**管理多个邮箱、测试连接、设置检查间隔和控制监听。编辑连接前先暂停，等待当前任务结束。
- **AI 服务：**选择和配置 AI，测试连接。
- **通用设置：**界面语言、报告目录、登录启动、更新和卸载。

顶部“帮助”提供中英西三语使用指南、授权码教程、检查更新和关于信息。离开有未保存改动的设置页会提示确认。

## 监听和报告

- 默认每 **60 秒**检查一次，可改为 **10–86400 秒**。
- **新添加邮箱第一次检查只记录当前位置，不会分析整个旧收件箱。** 已有进度时，恢复后补查暂停、关机期间的新邮件，前提是它们仍在所选文件夹中。
- 新报告保存为 `所选文件夹/收件邮箱地址/日期/From 发件邮箱地址/邮件标题-收到时间.md`，按北京时间命名，重名会避让。
- 报告列表可开启“报告树”，按邮箱 → 日期 → 发件人 → 报告逐层浏览，通过上一级和路径返回；关闭恢复平铺。搜索、日期、发件人和附件筛选同样适用。启动时整理可识别的旧报告并保留原邮件及对话关联。
- Markdown 显示标题、加粗、嵌套列表、链接、表格和代码块；旧 TXT 报告继续可读、可搜索、可筛选。
- 搜索使用本地已保存的正文、发件人、附件名和报告文字，不搜索整个远端邮箱。
- 修改保存位置只影响新报告，旧报告留在原处。

## 更新、退出和卸载

- 每小时自动检查更新，也可使用“帮助 → 检查更新”。软件内下载、显示进度并校验后，由您点击安装；保留配置和报告，安装失败时尝试恢复旧版。
- 关闭窗口后继续在菜单栏监听；点击信封可恢复。通过 Dock、菜单或 ⌘Q 退出会停止监听并保存暂停状态；重开后点“开始监听”恢复。
- 在“通用设置”打开卸载。配置和报告可分别选择保留；删除报告会再次确认。保留配置会保留本软件的钥匙串凭据，重装后继续使用；收信缓存和进度会清除。

## 连接失败

在“邮箱与检查”测试连接，展开或复制具体错误。新版会显示连接阶段、异常类型和脱敏后的服务器响应。
认证失败应检查账号和服务商要求的凭据；IMAP 未开启应检查网页邮箱或管理员设置；Unsafe Login 应查看服务商安全提醒；DNS、超时、TLS 错误应检查服务器、端口、网络、系统时间和代理。

## 数据与语言

邮箱凭据和 API Key 保存在登录钥匙串。来信与可提取的附件内容会发给选定的 AI；邮箱只读，不自动发送回复。图片、扫描件、加密或不支持的附件会说明读取限制；使用建议回复前，请核对原邮件。
首次启动按系统语言选择简体中文、西班牙文或英文，可在通用设置切换。新报告跟随界面语言，回复草稿使用来信语言；已有报告保持原文。

## 开发

源码位于 `Sources` 与 `Runtime`。完整环境准备、Apple 芯片／Intel 构建、离线测试和 DMG 打包步骤见 [开发构建说明](docs/DEVELOPMENT.md)。
普通用户使用 DMG 即可；Intel 版在 Apple 芯片 Mac 上通过 Rosetta 验证，不等同于真实 Intel 电脑测试。

## 语言与语言包

界面、安装程序和卸载程序支持**简体中文、英文、西班牙文**。首次使用：中文系统选择中文，西班牙语系统选择西班牙文，其他系统使用英文；之后可在通用设置切换。Windows 安装程序提供“下载简体中文”“下载英文”“下载西班牙文”。

切换到尚未安装的语言时，会提示“你没有下载这个语言，是否现在下载？”。确认后下载；取消或下载失败保留当前语言。新报告跟随所选语言，六项分析要求不变；已有报告不会自动翻译。英文名称为 **Email Assistant**，西班牙文名称为 **Asistente de correo electrónico**。

## 邮箱代理

每个邮箱可分别选择直连、系统代理、HTTP CONNECT 或 SOCKS5。在邮箱设置中打开高级连接与代理选项；启动 v2rayN 等代理软件，填写其实际监听地址、端口和协议，保存后测试连接。代理失败不会悄悄改成直连。这只影响 IMAP 测试与收信，不改变 AI API 网络；不支持 PAC 脚本或需要用户名密码的代理。

### macOS 首次打开被拦截

应用使用临时签名（ad-hoc），没有 Apple Developer ID 签名或 Apple 公证。先核对 GitHub Release 来源与 SHA256。尝试打开一次后，前往“系统设置 → 隐私与安全性”，若出现“仍要打开”，点击并确认后续提示。不要全局关闭 Gatekeeper；受管理电脑或没有允许选项时请联系管理员。

## 重新总结与邮件问答

选择报告后可点击“重新总结”，使用当前界面语言重新生成六项报告；生成失败会保留原报告。已有邮件索引用于重新分析，无需重新收信；缺少原始邮件索引的旧报告会给出提示。

“对邮件提问”支持围绕该邮件连续提问，并通过文件选择器添加补充文件。每封邮件分别保存完整聊天记录，重开后可继续。事实依据使用原邮件正文和可读取的原附件；模型也接收对话，但生成报告、旧回答和压缩摘要不作为事实来源；较早对话在过长时压缩为摘要，保留最近消息，并显示压缩状态。压缩不等于逐字保留，完整记录仍在本机；重要数字或原文请引用并核对。

这两项操作会调用已配置的 AI，可能产生费用。补充文件只读提取文字；无法读取或超过限制会明确报错，不会发送邮件。聊天记录保存在本机应用数据中；卸载会清除聊天记录，即使选择保留邮箱及 AI 配置。卸载前请复制需要保留的对话。

## 屏蔽邮件与垃圾邮件

在“邮箱与检查 → 屏蔽邮件”选择黑名单或白名单。黑名单内的发件人不会自动总结；白名单只总结列出的发件人，空白名单会跳过所有新邮件。规则适用于所有已添加邮箱，邮箱地址不区分大小写，按完整地址匹配。可以添加、批量选择和移除地址。

“不总结垃圾邮件（部分邮箱可能不支持）”只依据邮箱明确提供的垃圾邮件标记、邮件头或垃圾文件夹识别，不按标题猜测，不调用 AI 判断。仅检查所配置的邮件文件夹；服务商不提供标记时无法识别。此选项默认关闭。

被跳过的邮件在屏蔽记录中按发件人分组，可单独或批量“总结此邮件”，使用当前语言和 AI 设置。手动总结仅覆盖这一次，不改变规则；失败保留记录。“删除此记录”仅清除本地记录，不删除邮箱中的原邮件。屏蔽规则对之后检查到的新邮件生效，不清除已有报告。

报告和“对邮件提问”之间的分隔线可拖动，按需要调整两个区域的大小。

## 新增工作流与可靠性改进

- **回复草稿：**按语气、语言和补充要求生成，编辑收件人、主题与正文后保存为本地草稿或复制；不会自动发送邮件。
- **附件阅读增强：**图片和扫描 PDF 优先使用系统本地 OCR，提取的文字再交给所选 AI；系统语言支持、文件大小和识别质量有限制，无法读取会说明原因，不保证准确识别。
- **历史邮件补总结：**选择邮箱和日期，先预览待处理数量，确认后入队；处理可能产生 AI 费用，仍遵守发件人及垃圾邮件规则。
- **来源核对与连续问答：**查看已保存的原邮件、附件提取结果及读取限制。问答以原邮件和可读取的原附件为事实依据，报告和历史 AI 回答不能替代原始证据；缺少旧邮件来源时会提示。
- **通知与免打扰：**系统通知开关独立于开始／暂停监听；免打扰期间继续检查和保存报告，可设置跨午夜时段。
- **诊断包：**手动导出脱敏运行信息，便于排障；不包含密钥、邮件正文、附件或聊天原文。
- **整页统一保存：**邮箱、AI、通用设置各页集中保存；改动先暂存，离开有未保存改动的页面时提示确认。语言、报告目录与登录启动在通用设置中管理。

## 费用来源与账户余额

在“AI 服务 → 查看用量记录”查看输入／输出 Token、上游返回费用、本地估算及各自覆盖的调用数。上游费用优先；同一次调用不会重复计入本地估算。费用缺失时按已保存单价和用量估算，信息不足则显示“未知”。不同币种不相加，历史记录不会被猜测或追溯改价。

官方 OpenRouter 响应中的 `usage.cost` 按 USD 记录；兼容接口必须显式返回 `usage.cost` 与 `cost_currency`，或返回含 `amount`／`currency` 的 cost 对象。没有这些字段的服务商继续使用估算。上游返回值不能代替最终账单。

“查询账户余额”只在手动点击时请求，支持官方 DeepSeek、OpenRouter 地址，不生成 AI 内容。余额属于整个服务商账户，可能由其他软件共用，不能据余额变化推算小秘书消费。OpenRouter 余额接口需要相应管理权限，普通推理 Key 可能被拒绝；不建议为查余额替换成管理 Key。失败不会显示为零余额。
